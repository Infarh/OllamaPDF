# OllamaPDF

Небольшой экспериментальный проект, который проходит по PDF-файлам в указанной папке, извлекает текст (с ограничением длины) и отправляет его в локально запущенный **Ollama**, чтобы получить:

- предложенное *имя файла* (латиница/цифры/подчёркивания, без расширения)
- *краткое описание на русском* (до ~500 символов)

В репозитории есть две реализации одного и того же сценария:

- **Python**: `python/program.py`
- **C# (.NET 10)**: `csharp/OllamaPDF/Program.cs`

> По умолчанию в обеих реализациях используются:
> - модель: `mistral:latest`
> - путь к данным: `d:\123\pdf` (нужно изменить под себя)

---

## Возможности

- Рекурсивный поиск `*.pdf` в заданной директории
- Извлечение текста из первых страниц с ограничением по длине (по умолчанию `5000` символов) и попыткой резать по границе предложения
- Запрос к Ollama:
  - Python: HTTP POST `http://localhost:11434/api/generate`
  - C#: пакет `Ollama` (клиент `OllamaApiClient`)
- Формат ответа модели ожидается **JSON**:
  ```json
  {"filename":"suggested_filename","summary":"краткое описание на русском"}
  ```
- Повторы при ошибках/таймаутах (по умолчанию 3 попытки)

## Быстрый старт (Python)

Код находится в папке `python/`.

### 1) Установить Python
Нужен **Python 3.12+**.

Проверка:
```bat
py -V
```

### 2) Инициализировать окружение
Скрипт создаст `.venv`, активирует окружение в текущем окне и установит зависимости из `requirements.txt`.

Из папки `python`:
```bat
InitVenv.bat
```

Зависимости (фиксированные версии) лежат в `python/requirements.txt`:
- `pypdf==6.8.0`
- `requests==2.32.5`
- и т.д.

### 3) Настроить путь к PDF и (при необходимости) модель
Откройте `python/program.py` и измените:

- `DATA_PATH = Path(r"d:\123\pdf")`
- `MODEL_NAME = "mistral:latest"` (опционально)

### 4) Запуск
```bat
Start.bat
```

Альтернатива ручного запуска:
```bat
.\.venv\Scripts\python.exe .\program.py
```

## Переменные/настройки, на которые стоит обратить внимание

### Python (`python/program.py`)
- `MODEL_NAME` — имя модели Ollama
- `DATA_PATH` — папка с PDF
- `MAX_TEXT_LEN` — максимум извлекаемого текста (символов)
- `MAX_ATTEMPTS` — число попыток
- `REQUEST_TIMEOUT_SEC` — таймаут одного запроса
- `OLLAMA_URL` — URL генерации (`/api/generate`)

### C# (`csharp/OllamaPDF/Program.cs`)
- `model_name`, `data_path`
- `max_text_len`, `max_attempts`, `request_timeout_sec`

## Частые проблемы

### «Директория не существует»
Проверьте, что путь `DATA_PATH` (Python) / `data_path` (C#) существует и это именно папка.

### Нет ответа от модели / таймауты
- Убедитесь, что Ollama запущена и доступна по `http://localhost:11434`
- Убедитесь, что модель скачана (`ollama list`)
- Увеличьте `REQUEST_TIMEOUT_SEC` / `request_timeout_sec`
- Уменьшите `MAX_TEXT_LEN` / `max_text_len`

### Модель возвращает невалидный JSON
Код пытается распарсить JSON, но при ошибке выводит текст ответа. Если это происходит часто — поправьте prompt или смените модель.
